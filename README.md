# rec.verter

Достаёт звук из видео прямо на телефоне. Без сервера, без рекламы, без лимитов.

Кидаете видео через «Поделиться» — получаете аудиофайл. Часовой ролик обрабатывается
за секунды и работает в авиарежиме, потому что ничего никуда не отправляется.

## Зачем

На Android нет инструмента, который просто берёт видео и отдаёт звук. Всё, что есть в
маркете, либо просит подписку, либо показывает рекламу, либо грузит ваш файл на чужой
сервер и заставляет ждать очередь. Пять установленных приложений не справились с этой
задачей — отсюда проект.

## Как это может быть быстро

Аудиодорожка уже лежит внутри `.mp4` отдельным потоком. Её не нужно конвертировать —
достаточно вынуть. Системные `MediaExtractor` и `MediaMuxer` копируют поток байт в байт,
без перекодирования и без потери качества.

Приложения, которые заставляют ждать ради «конвертации», делают лишнюю работу — обычно
ещё и на чужом сервере.

## Форматы

| Формат | Как получается | Скорость | Качество |
|---|---|---|---|
| **M4A / AAC** | поток копируется из контейнера как есть | мгновенно | без потерь относительно оригинала |
| **WAV** | декодирование в PCM | быстро | без потерь, файл большой |
| **MP3** | декодирование в PCM, затем кодирование | медленнее | повторное сжатие |

M4A стоит первым не случайно: это тот же звук, что и в исходном видео, вынутый без
единого пересчёта. MP3 нужен там, где важна совместимость со старым софтом.

## Статус

Ранняя разработка. Первая цель — извлечение звука и выбор формата.

Дальше по плану — расшифровка речи в текст, тоже полностью на устройстве, с экспортом
в SRT и обычный текст. Записи и распознавание не покидают телефон.

## Стек

- React Native (Expo, dev client) + TypeScript
- Нативный модуль на Kotlin: `MediaExtractor` / `MediaCodec` / `MediaMuxer`
- Приём файлов через системный share sheet
