## Полное описание

1791 символ из 4000; до кнопки «развернуть» (около 2000) помещается целиком.

```
rec.verter достаёт звуковую дорожку из видео и сохраняет её отдельным файлом. Всё считается на самом телефоне: ни видео, ни готовое аудио никуда не отправляются.

Как пользоваться
1. Откройте видео в галерее, мессенджере или файловом менеджере.
2. Нажмите «Поделиться».
3. Выберите rec.verter и формат — готовый файл появится в папке Музыка/rec.verter.

Три формата и чем они отличаются
M4A — дорожка копируется из видео как есть, без перекодирования. Получается мгновенно, качество равно оригиналу.
WAV — звук раскодируется в несжатый PCM. Быстро, без потерь, но файл крупный: подходит для монтажа и расшифровки.
MP3 — звук раскодируется и сжимается заново. Дольше остальных и с повторным сжатием, зато открывается где угодно.

Работает без интернета
У приложения нет разрешения INTERNET — это видно в списке разрешений на странице приложения и проверяется в манифесте установленного APK. Отправить файл на сервер оно не может технически, поэтому работает в самолёте и в метро и не зависит от очереди на чужой стороне.

Файлы остаются на устройстве
Регистрации и входа нет. Аналитики, рекламы и сторонних SDK нет. Исходное видео приложение только читает и не изменяет; результат кладёт в общую медиатеку, откуда его видно любому плееру.

Разрешения и зачем они нужны
Доступ к файлам (чтение и запись, только Android 12 и старше) — прочитать видео, которое вы сами отправили в приложение через «Поделиться», и сохранить готовый аудиофайл в папку Музыка/rec.verter. На Android 13 и новее эти разрешения не запрашиваются вовсе: файл приходит по прямой ссылке от системы, а результат пишется через медиатеку.
Вибрация — короткий отклик на нажатия.
Других разрешений приложение не запрашивает.

Приложение бесплатное, без покупок и подписок. Ограничений на длительность видео и число файлов нет.
```

## Обоснования разрешений для консоли

Вписываются построчно в форму «Чувствительные разрешения» — по строке на
разрешение.

`READ_EXTERNAL_STORAGE` (объявлено с `android:maxSdkVersion="32"`):

```
Чтение видеофайла, который пользователь сам передал в приложение через системное меню «Поделиться», чтобы извлечь из него звуковую дорожку. Запрашивается только на Android 12 и ниже; на Android 13 и выше файл приходит по URI с временным доступом и разрешение не используется.
```

`WRITE_EXTERNAL_STORAGE` (объявлено с `android:maxSdkVersion="32"`):

```
Сохранение готового аудиофайла в общую папку Музыка/rec.verter, чтобы он был доступен плеерам и файловым менеджерам. Запрашивается только на Android 12 и ниже; на Android 13 и выше запись идёт через MediaStore и разрешение не используется.
```

Полный список разрешений релизного APK (`aapt2 dump permissions`):
`READ_EXTERNAL_STORAGE` (maxSdk 32), `WRITE_EXTERNAL_STORAGE` (maxSdk 32),
`VIBRATE` и служебное `com.hardelele.recverter.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`
(его добавляет androidx для внутренних broadcast-приёмников). `INTERNET` нет.

## Развёрнутая записка модератору

В поле карточки не влезает — держим на случай вопросов от модерации.

```
Авторизации в приложении нет: аккаунта, входа и тестовой учётной записи не требуется, весь функционал доступен сразу после установки.

Сеть не используется. Разрешение android.permission.INTERNET в манифесте отсутствует — это можно проверить командой aapt2 dump permissions на загруженном APK. Никакой аналитики, рекламы и сторонних SDK в сборке нет.

Как проверить работу за минуту:
1. Установите приложение и откройте любое видео в галерее.
2. Нажмите «Поделиться» и выберите rec.verter.
3. Выберите формат (M4A — самый быстрый) и нажмите «Извлечь звук».
4. Готовый файл появится в папке Музыка/rec.verter и будет виден в любом плеере; кнопки «Поделиться» и «Открыть» на экране результата отдают именно его.

Проверку можно проводить в авиарежиме: приложение полностью работает без сети.

Политика конфиденциальности: https://hardelele.github.io/rec.verter/privacy.html
```
